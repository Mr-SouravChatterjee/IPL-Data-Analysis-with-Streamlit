> Interactive multi-dimensional sports analytics web app covering all IPL seasons

## 🎯 What This Does

Full multi-tab analytics dashboard over the complete IPL dataset (2008–present) — team trends, player stats, match outcomes, and season comparisons, all deployed as an interactive web app.

## ✨ Features

- **Team Analysis** — Win rates, home/away performance, head-to-head matchups
- **Player Statistics** — Batting averages, bowling economy, strike rates
- **Match Outcome Modelling** — Toss impact, venue analysis, chasing vs defending
- **Season Comparisons** — Year-on-year performance trends
- **Real-time Filters** — Dynamic season, team, and player selectors

## 🛠️ Tech Stack

`Python` `Pandas` `Streamlit` `Plotly` `Matplotlib` `NumPy`

## 🚀 How to Run

```bash
git clone https://github.com/Mr-SouravChatterjee/IPL-Data-Analysis-with-Streamlit
cd IPL-Data-Analysis-with-Streamlit
pip install -r requirements.txt
streamlit run app.py
```
